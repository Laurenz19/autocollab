                1. Créer une clé d'API
                
          
                
            
            
            
          
                
        
                
        
                Une clé agit avec vos droits : vos agents, vos exécutions, vos connexions. Ne la partagez pas ; révoquez-la si elle a pu fuiter. Elle remplit automatiquement les exemples de cette page.
                
        
                
          Copiez votre clé maintenant : elle ne sera plus jamais affichée.
          
                
        
                
        
                
        
                Aucune clé pour l'instant.
                
      
                
      
                
        
                2. Appeler l'API
                
        
                Adresse de base : . Envoyez la clé dans l'en-tête Authorization: Bearer …. Réponses en JSON ; erreurs au format {"detail": "…"} (400 invalide, 401 non authentifié, 403 interdit, 404 introuvable, 409 conflit, 429 trop de tentatives).
                
        
                
        
                3. Suivre l'exécution
                
        
                Les exécutions sont asynchrones : interrogez GET /api/tasks/{id} jusqu'à un statut final, ou écoutez le flux d'événements (onglet Événements).

                            À chaque connexion, en plus du mot de passe, un code à 6 chiffres affiché par une application sur votre téléphone vous sera demandé. Un mot de passe volé ne suffit plus.
                            
        
                              
          
                            1. Installez une application d'authentification : Google Authenticator, Microsoft Authenticator, Authy, 1Password…
                              2. 
          
                            2. Scannez ce QR code avec l'application (ou saisissez la clé à la main).
                              3. 
          
                            3. Saisissez le code à 6 chiffres qu'elle affiche.
                              4. 
        
                            
        
                            
          
                            Clé (saisie manuelle)Type « basé sur le temps », 6 chiffres.
                            
        
                            
          
          
        
                            
      
                            
      
                            
        
                            Notez ces codes de secours et rangez-les en lieu sûr (pas sur le téléphone). Chacun permet une connexion si vous n'avez plus votre téléphone, une seule fois. Ils ne seront plus affichés.
