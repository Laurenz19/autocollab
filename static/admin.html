Applications proposées

Chaque utilisateur connecte son propre compte dans « Mes connexions ». Ses agents utilisent alors ces applications directement (serveurs MCP officiels), sans navigateur.

Données : le contenu lu par les agents (e-mails, fichiers, messages) est envoyé au fournisseur d'IA choisi dans l'onglet « Intelligence artificielle ».

Application Google (Gmail, Drive, Docs, Sheets, Agenda)

  1. Dans Google Cloud › Identifiants, créez un « ID client OAuth » de type Application Web.
  2. Ajoutez l'URI de redirection ci-dessous dans « URI de redirection autorisés ».
  3. Activez les API Gmail, Drive… et leurs services MCP (gmailmcp.googleapis.com, drivemcp.googleapis.com…). Guide Google
  4. Collez ici l'ID client et le code secret.

Application Slack

  1. Sur api.slack.com/apps, créez une application interne à votre espace de travail.
  2. Dans « OAuth & Permissions », ajoutez l'URI de redirection ci-dessous.
  3. Collez ici le Client ID et le Client Secret (onglet « Basic Information »).
